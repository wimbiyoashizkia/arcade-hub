# NeonPoi Arcade

A modern, web-based arcade platform built with vanilla JavaScript. Play classic mini games directly in your browser with seamless singleplayer and real-time multiplayer support.

## Features

- **Play instantly** - No downloads, no installations, no sign-ups required
- **Singleplayer mode** - Challenge the AI and test your skills
- **Multiplayer mode** - Play with friends online in real-time
- **Real-time connection** - Powered by WebRTC for seamless peer-to-peer connectivity
- **Fully responsive** - Optimized for desktop, tablet and mobile devices
- **Modern UI** - Neon themed design with smooth animations and interactions

## How It Works

1. Open the website in your browser
2. Choose a game from the arcade hub
3. Select Singleplayer to play against the computer
4. Select Multiplayer to create or join a game room
5. Share the Room ID with your friend and start playing together
